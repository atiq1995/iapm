## Reproduction
Use Python Pillow, NumPy and FFmpeg. render.py contains the exact edit decision list in shots and source timecodes. Set P, R and SOURCE to the working/output folder, checkout, and supplied reference movie respectively. Run render.py. It renders at the reference 1280x720 frame size and exports 1920x1080 at 24 fps with AAC 48 kHz, 90 seconds.
